# 分层导学模式

主产物是本地、离线、可交互的 HTML。聊天负责导航、说明更新、追问和下一步；完整知识沉淀在页面里。

## 五层推进

| 层级 | 本层应讲清 | 本层不要提前展开 |
| --- | --- | --- |
| 1 心智模型 | 一两句定位、为什么需要、极简流程、常见误解；类比后接一个具体例子 | 文件名、函数细节、重试时长和复杂边界 |
| 2 能干什么 | 3–5 个真实场景：用户提出什么、系统做什么、最后得到什么；归纳共同适用条件 | 实现调用栈 |
| 3 业务全链路 | 沿一个具体请求，从入口到结果串起角色、交接、数据和必要失败分支 | 脱离这条业务链的模块细节 |
| 4 架构总览 | 职责、状态归属、依赖与调用关系、交接序列、对象关系和关键架构纪律 | 每个类的逐段源码 |
| 5 逐模块实现 | 按依赖顺序，每轮一个模块群；回答状态、入口、协作、失败/重启四问 | 尚未研读模块的实现断言 |

默认每轮推进一层。用户已掌握、明确要求跳层或合并时，不机械重教；补齐必要前提即可。用户表示太细或无法接受时，回到前一层或缩小范围，用更具体的例子重写页面，不继续增加细节。规则模拟、自测和动手实验按内容需要添加，不强制每层出现；完整链路教学之后再做流程自测。

## 使用已确认的模板

复制 `../assets/layered-learning.html` 到目标项目后改写。模板是一个虚构后台任务系统的完整演示，**不代表真实项目事实，不可只替换项目名就交付**。

用户已选定的视觉与内容原则：

- 连续正文为主：定义 → 流程 → 完整例子 → 关键区别，段落之间有因果和承接。
- 减少碎片化卡片、微型标题、冗余标签和装饰性英文；不用夸张标题和大块留白拉长页面。
- 图概括关系，表比较差异，交互推演过程；需要连续阅读的说明不拆成一堆可点击卡片。
- 保持适当信息密度，不靠缩小字体堆内容。正文约 15–16 px，清晰的深灰文字，桌面正文容器约 960 px；手机自然换行。
- 顶部五步导航、白底、轻量蓝色选中态；实现细节和自测默认折叠。当前层目标可融入引言，不另加一排重复元信息。
- 阅读进度由用户主动确认；浏览或答对单题都不能自动认证理解。允许回看和自由跳转。

### 改写点

1. 更新 HTML 标题、项目名、页面标题、页脚与 `storageKey`。每个专题使用独立存储键，重大内容改版也应更新。
2. 用真实项目内容改写 `layers`、`scenarios`、`steps`、`modules`，以及对应正文生成函数。不是每个主题都要有任务队列、API、Worker 或六个业务步骤。
3. **只将已完成教学的层设为 `ready: true`，其余设为 `ready: false`。** 模板会显示待学习页；不能留下示例内容装作后续章节已完成。完成一层再更新其内容和标记。
4. 在已制作层的 `sources` 中放入 `{path, lines, note}` 数组：仓库相对路径、行号/范围和支持的论点。页面自动生成折叠的源码依据。行号要来自实际阅读，不填编造路径。
5. 源码和文本通过转义或 `textContent` 插入。模板使用受维护的本地内容；外部输入不能未经处理拼接进 `innerHTML`。
6. 改步骤数时同步改计数、路由取值边界和上一/下一步禁用条件；改模块/场景数量时同步更新相应路由边界。删掉不适用的交互和示例伪代码。
7. 当前页面默认是五层单文件结构，`#model` 等锚点可定位。状态筛选写入 hash 参数；进度仅存在当前浏览器，存储受限时允许降级为本次会话内使用。

## 事实与表达的分层

前几层用职责和业务词，不必让读者记类名；折叠源码依据保留“职责 → 实现路径”的映射。架构层开始列真实模块与代码位置，模块层给真实片段、数据结构和失败边界。所有层的项目结论都要核验，呈现简洁不代表可以省略研读。

## 文件与持续更新

- 整项目持续学习先按 `project-learning.md` 确定统一目录，并维护 `progress.md`；以下项目根目录规则只用于未启用持续学习的单次导学。
- 默认保存在项目根目录 `<主题>-learn.html`，按轮次更新同一份导读；用户指定目录则从其要求。避免落在会话临时目录。
- 已有用户文件不能直接覆盖；检查是否为本次正在维护的导读，否则使用新文件名或说明冲突。
- 主题很大时可以拆为 `<主题>-intro.html`（1–3）、`<主题>-architecture.html`（4）、`<主题>-guide.html`（5），保持同一套排版和互链。不要在未开展下一层时生成空文件充数。
- 后续更新也要用当前源码核验，不能把上轮页面当事实来源。聊天里简要说明当前层、阅读入口和下一层，默认等用户继续。

## HTML 验证

保持单文件、无远程字体/脚本/样式，离线可读。图用内联 SVG 或 HTML/CSS，不依赖 Mermaid CDN。

实际在浏览器检查：桌面及手机布局、长文字、中文换行、内部锚点/深链接、场景与模块切换、步骤前后边界、折叠区域、自测反馈、进度确认与取消。覆盖键盘焦点、手机目录关闭与焦点恢复、减少动态效果设置。不要把未检查的浏览器或屏幕阅读器写成已验证；临时预览服务用完关闭。

导航与动作使用原生链接、按钮，动态反馈有可访问提示。不要用颜色单独编码状态：执行中、失败、推断等都须有文字。保留单层打印能力；若未实现全册导出，不宣称支持。
